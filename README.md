# Momentum Board

A clean beginner-friendly productivity app for tracking small tasks and running a 25-minute focus timer. It saves tasks in the browser with `localStorage`, so the board stays there when you refresh.

## Features

- Add, complete, and delete tasks
- Visual progress ring
- Focus timer with 15, 25, and 50 minute modes
- Light and dark themes
- Browser storage with no account needed
- Responsive layout for phone and desktop

## Preview

Open `index.html` in your browser.

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Add a few tasks and start the focus timer.
